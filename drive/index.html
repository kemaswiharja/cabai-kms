Dashboard Sinkronisasi

Perbarui data
spesimen cabai
sekarang.

Sistem ini secara otomatis mengambil data dari Google Drive, memproses file Excel dan gambar, lalu memperbaruinya ke database MongoDB menggunakan kecerdasan buatan untuk pencocokan nama spesimen.

01
Unduh File Excel
Mengambil semua file .xlsx dari Google Drive secara langsung ke memori.
02
Proses & Gabungkan Data
Mentranspose dan menggabungkan data karakter spesimen dari semua Excel.
03
Perbarui MongoDB
Menghapus dokumen lama dan memasukkan data spesimen terbaru ke koleksi.
04
Publikasi Gambar
Menjadikan semua gambar di folder gambar dapat diakses publik.
05
Pencocokan AI
Mencocokkan nama file gambar ke nama spesimen di database sesuai aturan penamaan.
